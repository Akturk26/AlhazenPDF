# 📱 AlhazenPDF

Profesyonel PDF Oluşturucu - Galeri, Emlak ve Ofis İçin

## 🚀 Özellikler

- 📸 Kameradan/Galeriden Fotoğraf Yükleme
- 🎨 5 Farklı Hazır Şablon
- 🚗 Galeri (Araç) Şablonu
- 🏠 Emlak Şablonu
- 💼 Ofis/Kurumsal Şablon
- 📄 PDF Oluşturma ve Paylaşma

## 📦 Kurulum

\`\`\`bash
npm install
\`\`\`

## 🏃 Çalıştırma

\`\`\`bash
npm start
\`\`\`

## 📱 Test

- iOS: `npm run ios`
- Android: `npm run android`
- Web: `npm run web`
